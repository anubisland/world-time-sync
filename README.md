# توقيت العالم الذكي | World Time Sync (AnubisLand)

تطبيق ويب ذكي ومتكامل (PWA) لتحديد ومقارنة التوقيت بين مدن العالم في لحظة واحدة، مع مخطط اجتماعات ذكي على مدار 24 ساعة.

## المميزات الرئيسية
- **الوقت المباشر والوقت المخصص**: اعرض التوقيت الحالي مباشرة أو أدخل أي تاريخ ووقت في المدينة المرجعية لترى التوقيت المقابل في جميع المدن المختارة.
- **شريط التمرير الذكي (24 ساعة)**: اسحب الشريط لتجربة أي ساعة في اليوم ومراقبة تغيّر التوقيت والنهار والليل فوراً.
- **مخطط الاجتماعات الذكي (24-Hour Matrix)**: مصفوفة بصرية تكشف "الأوقات الذهبية المشتركة" التي يكون فيها الجميع في ساعات العمل، مع إمكانية الضغط على أي ساعة لتطبيقها فوراً.
- **بطاقات ملونة وتفاعلية**: كل مدينة ببطاقة ملونة تعرض التوقيت (12/24 ساعة)، التاريخ، فرق الساعات، حالة اليوم (أمس/نفس اليوم/غداً)، التوقيت الصيفي (DST)، وحالة النهار والعمل.
- **ثنائي اللغة ومظهر فاتح/داكن**: دعم كامل للغة العربية (RTL) والإنجليزية (LTR)، مع مظهر فاتح وداكن واختيار نوع وحجم الخط.
- **تطبيق ويب تقدمي (PWA)**: قابل للتثبيت على الهاتف أو الحاسوب ويعمل بدون إنترنت.
